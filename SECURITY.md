# Security Policy

## Supported Versions

This project has not published a stable release yet. Security fixes currently apply to the latest development version on the default branch.

Once releases begin, this section will be replaced with a supported-versions table.

## Reporting a Vulnerability

**Do not** report security vulnerabilities through public GitHub issues, pull requests, or discussions.

GitHub's private vulnerability reporting is not enabled yet on this repository and will be enabled before the first public release. Until then:

1. Open a public issue titled "Security contact request" that contains **no vulnerability details** — just a request to be contacted privately.
2. A maintainer will follow up to arrange a private channel for you to share the details.

Once private reporting is enabled, this document will be updated with the direct reporting link, and vulnerability details should be submitted there instead.

When you do report a vulnerability (privately), please include as much of the following as you can:

- A description of the vulnerability and its potential impact
- Steps to reproduce, or a proof of concept
- The affected version/commit
- Any known mitigations
