# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | ✅        |
| < 0.1.0 | ❌        |

Pre-1.0: only the latest `0.x` minor receives security fixes.

## Reporting a Vulnerability

**Do not** report security vulnerabilities through public GitHub issues, pull requests, or discussions.

Use GitHub's private vulnerability reporting instead: [Report a vulnerability](https://github.com/School-of-Company/nestjs-eureka/security/advisories/new).

Please include as much of the following as you can:

- A description of the vulnerability and its potential impact
- Steps to reproduce, or a proof of concept
- The affected version/commit
- Any known mitigations
